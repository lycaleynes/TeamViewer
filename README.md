# How to Use TeamViewer (Step-by-Step)

TeamViewer is a remote access and control software that allows you to connect to another computer or let someone connect to yours. Below is a basic guide for using TeamViewer after it is installed.

## Step 1: Open TeamViewer

Launch the TeamViewer application on your computer.

<p align="center"><img src="https://i.imgur.com/joUD2L3.png" height="80%" width="80%" alt="TeamViewer"/></p>

## Step 2: Locate Your ID and Password

On the main TeamViewer window, you'll see:

- **Your ID**: This is the number you share with the person who wants to connect to your computer.
- **Password**: This is a temporary password required to access your computer.

<p align="center"><img src="https://i.imgur.com/joUD2L3.png" height="80%" width="80%" alt="TeamViewer"/></p>

## Step 3: Connect to Another Computer

To connect to someone else’s device:

1. Get their **TeamViewer ID**.
2. Enter it in the field labeled **“Partner ID”** under *Control Remote Computer*.
3. Select **Remote control** and click **Connect**.

<p align="center"><img src="https://i.imgur.com/5MBKCbl.png" height="80%" width="80%" alt="TeamViewer"/></p>

## Step 4: Enter the Partner’s Password

When prompted, enter the password the other person gave you.

<p align="center"><img src="https://i.imgur.com/FV2kB5g.png" height="80%" width="80%" alt="TeamViewer"/></p>

## Step 5: Wait for the Connection to Establish

After the password is accepted, you will be connected to the remote machine and see their desktop.

<p align="center"><img src="https://i.imgur.com/DUwzp6R.png" height="80%" width="80%" alt="TeamViewer"/></p>

## Step 6: Use the Toolbar

Once connected, you’ll see a toolbar at the top of the screen. It includes:

- File transfer
- Chat
- Screen scaling
- Session recording
- Disconnect

Use these tools to manage your remote session.

<p align="center"><img src="https://i.imgur.com/DLPZtfT.png" height="80%" width="80%" alt="TeamViewer"/></p>

## Step 7: End the Session

To end the session, click **X** on the TeamViewer toolbar or close the TeamViewer window.

<p align="center"><img src="https://i.imgur.com/owBQhB3.png" height="80%" width="80%" alt="TeamViewer"/></p>

## Tips for Secure Use

- Only share your ID and password with people you trust.
- Each time TeamViewer restarts, a new password is generated (unless set otherwise).
- Enable two-factor authentication for added security.
